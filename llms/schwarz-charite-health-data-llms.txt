# Schwarz Charite Health Data

> Schwarz Charite Health Data GmbH is a German health-data joint venture announced on 2026-03-20 by
> Charite - Universitaetsmedizin Berlin (25%) and Schwarz Digits (75%), the IT and digital arm of the
> Schwarz Group. It brings the HIVEPRO platform to market: an openEHR-based Clinical Data Repository
> queried with Archetype Query Language (AQL), exchanging data over HL7 FHIR (including the German
> Medical Informatics Initiative core dataset) and feeding OMOP-compliant analytics, delivered as a
> managed service on STACKIT's sovereign cloud so data residency stays in Germany.

## What an agent can call today

Nothing. As of 2026-09-02 this company publishes no API. There is no website of its own, no developer
portal, no documentation host, no API reference, no OpenAPI/GraphQL/AsyncAPI/MCP/WSDL/gRPC contract, no
SDK, no CLI, no sandbox, no status page and no pricing page. Every named /.well-known/ path on the only
host associated with the company (schwarz-digits.de, its parent) returned HTTP 404, negative control
included. Do not attempt to construct a base URL or an endpoint for this provider; none is published.

## Standards

- openEHR - Clinical Data Repository core; company is a listed openEHR International industry partner.
- Archetype Query Language (AQL) - the query surface of the repository.
- HL7 FHIR - stated interoperability surface, including the MII core dataset.
- OMOP CDM - stated support for OMOP-compliant consuming applications (interoperability, not an OMOP implementation).
- STACKIT sovereign cloud / EU GDPR - stated hosting and data-residency posture.

Standards are recorded from published prose, not from a parsed contract. See
conformance/schwarz-charite-health-data-conformance.yml for what is membership-verified versus claimed.
